# 名言シャッフル（meigen）

開くと名言がランダムに1つ大きく表示される、スマホ向けのシンプルな1画面 Web アプリです。
**サーバー不要のstaticサイト**として動き、外部APIやAPIキーは一切使いません。

## ✨ 特徴

- **ランダム表示** … 開くたびに名言が1つ大きく表示されます。
- **シャッフル操作** … 「次の名言」ボタン / 画面タップ / 左右スワイプ のどれでもOK。
- **フェードアニメーション** … 切り替え時にふわっとフェードイン／アウト。
- **本文＋人物名（出典）** をセットで表示。
- **お気に入り（♡）/ コピー / シェア** ボタン付き（お気に入りは端末内に保存）。
- **ダークでおしゃれなデザイン** … グラデーション背景＋ゆっくり動く装飾。
- **PWA対応** … ホーム画面に追加してアプリのように起動でき、オフラインでも動作。

## 📁 ファイル構成

```
meigen/
├── index.html      … アプリ本体（HTML / CSS / JS）
├── quotes.js       … 名言データ（← ここだけ編集すればOK）
├── manifest.json   … PWA設定
├── sw.js           … Service Worker（オフライン対応）
├── icons/          … アプリアイコン
└── scripts/
    └── make_icons.py … アイコン生成スクリプト（任意・再生成用）
```

## 📝 名言の追加・差し替え

名言は **`quotes.js` だけ** を編集すれば増やせます。形式は配列で、1件ずつ
`{ text: "名言の本文", author: "人物名" }` を追加するだけです。

```js
const QUOTES = [
  { text: "ここに名言の本文", author: "人物名（出典）" },
  // ↑ こんな感じで何個でも追加できます（末尾のカンマを忘れずに）
];
```

> 現在は名言を **200個** 収録しています。差し替えたいときは、この配列の中身を
> 入れ替えてください。

### 💡「意味」をつける（任意）

分かりづらい名言には、`note` を足すと本文の下に **「意味をみる」ボタン** が表示され、
タップで解説が開きます。`note` を書いたものだけボタンが出るので、付けたいものにだけ
付ければOKです。

```js
const QUOTES = [
  {
    text: "天上天下唯我独尊",
    author: "釈迦（ブッダ）",
    note: "人は誰もが、他に代えのきかない尊い存在として生きている、という意味です。"
  },
  { text: "解説のいらない名言", author: "誰か" }, // note なし → ボタンは出ない
];
```

> Gemini に200個を作ってもらうときに「分かりづらいものには `note`（意味の解説）も
> 付けて」とお願いすれば、まとめて解説付きにできます。

💡 PWAとしてホーム画面に追加した後に名言を更新した場合、すぐ反映されないことが
あります。その場合は `sw.js` の先頭にある `const CACHE = "meigen-v1";` の
バージョン番号を1つ上げる（例: `meigen-v2`）と確実に最新版が読み込まれます。

## 🚀 Vercel で公開する手順

このアプリはビルド不要の静的サイトなので、**設定はほぼ不要**です。

### 方法A：GitHub連携（おすすめ・一番かんたん）

1. このリポジトリを GitHub にプッシュする（すでに済んでいます）。
2. [https://vercel.com](https://vercel.com) にアクセスし、GitHub アカウントでログイン。
3. **「Add New…」→「Project」** をクリック。
4. この `meigen` リポジトリを選んで **Import**。
5. 設定画面では何も変更せず（Framework Preset は **Other**／ビルドコマンドは空のまま）、
   そのまま **「Deploy」** をクリック。
6. 数十秒で `https://meigen-xxxx.vercel.app` のような URL が発行され、公開完了です 🎉

以降は GitHub にプッシュするたびに自動でデプロイされます。

### 方法B：Vercel CLI を使う

```bash
npm i -g vercel      # 初回のみ
cd meigen
vercel               # 画面の指示に従う（質問はすべてEnterでOK）
vercel --prod        # 本番公開
```

## 📱 ホーム画面への追加（PWA）

公開URLをスマホのブラウザで開き、

- **iPhone (Safari)** … 共有ボタン →「ホーム画面に追加」
- **Android (Chrome)** … メニュー →「アプリをインストール」／「ホーム画面に追加」

でアプリのように起動できます。

## 🛠 ローカルで動かす（任意）

PWA / Service Worker を試すには、`file://` ではなくローカルサーバー経由で開きます。

```bash
cd meigen
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

---

外部APIなし・環境変数なし・サーバーなしで動く、完全な静的アプリです。
